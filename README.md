# Agent Skills

[![skills.sh](https://skills.sh/b/kinanlak/skills)](https://skills.sh/kinanlak/skills)

Practical skills for AI coding agents.

## Available skills

### agent-ready

Manual (`/agent-ready`). Audit a repository and scaffold what agents need to work in it alone: AGENTS.md, a private seeded instance per worktree, `t3.json`, a test skill, CI and delivery rules.

### browser-verify

Verify a user-visible change, or review a UI, through a fresh GPT-6.1 Terra subagent at high effort with a complete brief and fixed verdicts. Needs T3 Code and a Codex provider.

### retex

Turn what a session, a thread or a period of work taught into reviewed edits to skills, AGENTS.md or docs, instead of private agent memory.

### dep-updater

Audit dependency updates, assess project impact, and apply safe changes with the appropriate package manager.

```bash
npx skills add kinanlak/skills
```
